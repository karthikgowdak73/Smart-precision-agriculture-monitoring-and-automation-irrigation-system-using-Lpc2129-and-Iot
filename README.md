Smart Precision Agriculture Monitoring and Automated Irrigation System Using LPC2129 and IoT is an intelligent agricultural system designed to monitor important environmental and soil conditions and automatically provide water to crops whenever irrigation is required.

Features 🌱 Soil moisture monitoring 💧 Automatic water pump control 🌧️ Rain detection 🌡️ Temperature & humidity monitoring 🔥 Fire detection 🚨 Motion/security detection 📡 ESP8266 + ThingSpeak IoT monitoring 💾 EEPROM & SD card data logging ⏰ DS1307 RTC 🔗 UART, I²C, SPI, ADC & CAN communication Technologies

Embedded C | LPC2129 ARM7 | ESP8266 | IoT | Sensors | UART | I²C | SPI | CAN

The system helps reduce water wastage, automate irrigation, and enable remote agricultural monitoring.

The system provides additional agricultural safety features:

Flame detection: Activates the buzzer and generates a fire alert. Motion detection: Generates a security alert when movement is detected. Low water protection: Prevents the pump from operating when the tank water level is low.
